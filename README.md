# hello-claude-pr

A tiny arithmetic library used to practice opening pull requests.

## Usage

```python
from calc import add, subtract, multiply, divide

add(2, 3)       # 5
subtract(5, 2)  # 3
multiply(4, 3)  # 12
divide(10, 2)   # 5.0
```

Each function receives two numbers and returns the result.

## Tests

Run the tests with:

```bash
python -m unittest test_calc.py
```
